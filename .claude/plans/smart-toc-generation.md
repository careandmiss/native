# Plan: Smart TOC generation on the manual-mapping path

## Background

`run_with_mapping` (pipeline.py:1899) is the "manual mapping + markdown section
cloning" workflow. It currently handles `expand_*_template` for divider + content
slides cloned from H1 sections, but it does NOT handle the **TOC slide**.

Today the TOC is filled one of two ways:
- **LLM path** (`llm_plan=True`): TOC is generated by `llm_planner.py` and
  shipped through `page_plan` → `phase3_author`. Boteng caller doesn't use this.
- **Manual path** (current boteng caller): caller hand-fills 1 TOC entry in
  `BOTENG_MAPPING.slide_02` (shape-69/70/71/72). Remaining 5 slots either
  render as template defaults ("单击添加大标题", "第五章", ...) or get cleaned up
  by `_remove_empty_toc_slots` (which **deletes** the entire `<g>`, leaving
  blank gaps in the 3×2 grid).

**Goal**: even when callers go through the manual mapping path, the TOC slide
should be auto-generated from the markdown H1s.

**Key constraints** (from user feedback):
- TOC layouts vary across templates → no hardcoded layout (3×2, 2×3, etc.)
- Pure SVG parsing for slot detection is "杀鸡用牛刀" (overkill) → keep
  template-specific knowledge on the caller side
- The truly "smart" parts are: TOC slide auto-detection, clear (don't
  delete) on < N, clone on > N — these don't require SVG parsing

## Design (decided Option B)

| Element        | Design                                                                          |
|----------------|---------------------------------------------------------------------------------|
| Caller config  | Two ordered lists: `toc_slot_title_ids` (required), `toc_slot_subtitle_ids` (optional) |
| Auto-detect    | Function auto-detects which slide is the TOC (looks for 目录/CONTENTS marker)   |
| < N behavior   | Fill first N slots; clear (empty `<text>`) remaining slots. Keep `<g>` shape.   |
| > N behavior   | Clone TOC slide as `slide_partNN_toc.svg` for each overflow batch.              |
| Master switch  | `expand_toc_from_markdown: bool = False`                                        |
| Side effect    | When `expand_toc_from_markdown=True`, drop any manual `content_mapping` entries targeting TOC shape ids. |

### `pipeline.expand_workspace_from_toc`

```python
def expand_workspace_from_toc(
    workspace: Path,
    md_path: Path,
    *,
    toc_slot_title_ids: list[str],
    toc_slot_subtitle_ids: list[str] | None = None,
    toc_svg: str | None = None,
    part_names: list[str] | None = None,
) -> dict[str, Any]:
    """Fill the TOC slide from markdown H1s using caller-supplied slot ids.

    Parameters
    ----------
    workspace:
        Authoring workspace root. Must contain ``authoring-svg-flat/``.
    md_path:
        Markdown file; H1s define section titles to fill into the TOC.
    toc_slot_title_ids:
        Ordered list of shape-* ids that receive the chapter titles.
        Row-major fill order. Required.
    toc_slot_subtitle_ids:
        Optional parallel list of shape-* ids that receive the chapter
        subtitles. If given, must have the same length as
        ``toc_slot_title_ids``. If omitted, subtitle slots are cleared.
    toc_svg:
        Optional explicit TOC SVG filename. Auto-detected (first slide
        containing "目录" / "CONTENTS") if None.
    part_names:
        Optional explicit list of section titles. Defaults to all H1s in
        the markdown.

    Behaviour
    ---------
    * N <= slots_total: edit toc_svg in place. Fill first N slots; clear
      remaining. Slot <g> shapes preserved (only <text> emptied).
    * N > slots_total: fill first batch in toc_svg. For each subsequent
      batch of ``slots_total`` items, clone toc_svg as
      ``slide_partNN_toc.svg`` (where NN is the part index) and fill.
      page_plan.json is updated to include clones after the original TOC.

    Returns
    -------
    {
        "toc_svg": str,
        "slot_count": int,
        "filled": int,
        "cloned_svgs": list[str],
    }
    """
```

## Implementation outline

```python
def expand_workspace_from_toc(
    workspace, md_path, *,
    toc_slot_title_ids, toc_slot_subtitle_ids=None,
    toc_svg=None, part_names=None,
):
    auth = workspace / "authoring-svg-flat"
    if toc_svg is None:
        toc_svg = _find_toc_svg(auth)

    sections = _split_markdown_sections(md_path.read_text(encoding="utf-8"))
    titles = part_names or [s["title"] for s in sections]
    n_total = len(titles)
    slot_count = len(toc_slot_title_ids)
    has_subtitles = toc_slot_subtitle_ids is not None

    # === < N case: edit toc_svg in place ===
    fill_n = min(n_total, slot_count)
    edits = _build_slot_edits(
        titles[:fill_n], range(fill_n),
        toc_slot_title_ids, toc_slot_subtitle_ids, mode="fill",
    )
    if fill_n < slot_count:
        edits.update(_build_slot_edits(
            [], range(fill_n, slot_count),
            toc_slot_title_ids, toc_slot_subtitle_ids, mode="clear",
        ))
    svg_edits.apply_text_edits(auth / toc_svg, edits)

    # === > N case: clone toc_svg per overflow batch ===
    cloned = []
    if n_total > slot_count:
        for batch_idx, batch_start in enumerate(
            range(slot_count, n_total, slot_count), start=2
        ):
            clone_name = f"slide_part{batch_idx:02d}_toc.svg"
            shutil.copy2(auth / toc_svg, auth / clone_name)
            batch_titles = titles[batch_start:batch_start + slot_count]
            fill_n = len(batch_titles)
            clone_edits = _build_slot_edits(
                batch_titles, range(fill_n),
                toc_slot_title_ids, toc_slot_subtitle_ids, mode="fill",
            )
            clone_edits.update(_build_slot_edits(
                [], range(fill_n, slot_count),
                toc_slot_title_ids, toc_slot_subtitle_ids, mode="clear",
            ))
            svg_edits.apply_text_edits(auth / clone_name, clone_edits)
            cloned.append(clone_name)

    # === Update page_plan.json: append clones after original TOC ===
    if cloned:
        _append_toc_clones_to_page_plan(
            workspace, toc_svg, cloned, slot_count,
        )

    return {
        "toc_svg": toc_svg,
        "slot_count": slot_count,
        "filled": n_total,
        "cloned_svgs": cloned,
    }
```

`_build_slot_edits(titles_for_slots, slot_indices, title_ids, sub_ids, mode)`:

```python
def _build_slot_edits(titles, slot_indices, title_ids, sub_ids, mode):
    edits = {}
    for i, slot_idx in enumerate(slot_indices):
        title = titles[i] if mode == "fill" and i < len(titles) else ""
        edits[title_ids[slot_idx]] = title
        if sub_ids is not None:
            edits[sub_ids[slot_idx]] = title  # subtitle = title by default;
                                              # caller can post-edit
    return edits
```

`_find_toc_svg(auth)`:

```python
def _find_toc_svg(auth: Path) -> str:
    for p in sorted(auth.glob("slide_*.svg")):
        text = p.read_text(encoding="utf-8")
        if "目录" in text or "CONTENTS" in text.upper():
            return p.name
    raise ValueError(
        f"No TOC slide found in {auth}: no slide contains '目录' or 'CONTENTS'. "
        "Pass toc_svg explicitly."
    )
```

## Side effect: drop conflicting manual mapping entries

```python
# In run_with_mapping, when expand_toc_from_markdown=True:
if expand_toc_from_markdown:
    toc_shape_ids = set(expand_toc_slot_title_ids or [])
    if expand_toc_slot_subtitle_ids:
        toc_shape_ids.update(expand_toc_slot_subtitle_ids)
    for svg_name in list(content_mapping):
        original = content_mapping[svg_name]
        kept = {k: v for k, v in original.items() if k not in toc_shape_ids}
        if len(kept) != len(original):
            content_mapping[svg_name] = kept
            log.info(
                "expand_toc_from_markdown: dropped %d manual TOC mapping "
                "entries in %s (shape_ids: %s)",
                len(original) - len(kept), svg_name,
                [k for k in original if k not in kept],
            )
    edit_summary.setdefault("dropped_toc_entries", 0)
    edit_summary["dropped_toc_entries"] += len(original) - len(kept)
```

```python
def test_expand_toc_clones_overflow(tmp_workspace):
    _make_toc_workspace(tmp_workspace, slots=6)
    md = tmp_workspace / "m.md"
    md.write_text("\n".join(f"# Title{i}" for i in range(1, 9)))
    result = pl.expand_workspace_from_toc(
        workspace=tmp_workspace, md_path=md,
        toc_slot_title_ids=[f"shape-title-{i}" for i in range(6)],

    assert result["cloned_svgs"][0] == "slide_part02_toc.svg"
    assert (auth / "slide_part02_toc.svg").is_file()
    # Original: titles 1-6
    original_text = (auth / "slide_02.svg").read_text()
    for i in range(1, 7):
        assert f">Title{i}<" in original_text
    # Clone: titles 7-8 in slots 0-1, slots 2-5 cleared
    clone_text = (auth / "slide_part02_toc.svg").read_text()
    assert ">Title7<" in clone_text
    assert ">Title8<" in clone_text
```

## Out of scope (v1)

- Auto-detection of slot ordering from SVG (rejected as overkill).
- Subtitle content generation (currently mirrors title; caller can post-edit).
- Multi-page overflow re-ordering in page_plan.json (appended at end for v1;
  can be re-ordered to be contiguous with original TOC in a follow-up).
- Detection of subtitle shape ids from font-size heuristic (caller decides
  via parallel list).
